Landing Page oficial do consultório **José Patrício Odontologia**, desenvolvido com foco em uma experiência moderna, elegante e responsiva para pacientes que buscam qualidade, tecnologia e resultados naturais.

## 📌 Sobre o Projeto

Site institucional desenvolvido para apresentar:

- Serviços odontológicos

- Estrutura do consultório
- Informações do profissional
- Formulário de contato

Transmitir confiança, excelência e humanização, destacando a filosofia:
